## Carry-Forwards

- **Lightbox testing:** The lightbox was not explicitly tested this session for all six images, overlay close, ESC close, or focus trapping. Session 010 or a later QA pass should verify.
- **Gallery max-width:** The `max-width: 1680px; margin-inline: auto` pattern was not applied to the gallery. The horizontal-scroll gallery may not need it (it stretches full width by design), but this should be confirmed.
- **Scrollbar standard properties removed:** The gallery scrollbar relies entirely on `-webkit-scrollbar` pseudo-elements. Firefox uses `scrollbar-color` (standard) — the gallery scrollbar will use Firefox's default styling. If Firefox support matters, consider adding `scrollbar-color` back as a fallback (accepting that height/arrow hiding won't apply there).
- **Modal JS class mismatch:** The JS adds `modal__container--lightbox` to the container element, but CSS targets `.modal--lightbox .modal__container` (parent-child). The lightbox width override at desktop was never applying. Not a problem now since mobile is fullscreen and desktop uses the base `min(90vw, 800px)`, but should be fixed if a wider desktop lightbox is desired.
- **Gallery images not CMS-managed:** Images are hardcoded in `index.html`. If the user wants CMS control over gallery images later, a list renderer in `load-content.js` will be needed.
