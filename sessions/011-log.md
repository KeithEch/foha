- **Round 2 revisions:**
  - `.retail__content-col` desktop `max-width` 747px → 560px (25% narrower). At 1024px the column is space-constrained (~351px) so the change is only visible at 1280px+.

- **Round 3 revisions:**

  - itch button background matched to the badge's `#222` (read from the SVG's first `<path fill>`). No token matched; user approved an exact-match token: `--primitive-neutral-875: #222222` → `--color-bg-action-itch`. Added to `tokens.css`, `DESIGN-SYSTEM.md`, and `preview.html`.
  - Deleted `public/images/itch-cover.jpg` (confirmed no remaining references).
- Verified each round with Playwright (installed in the session scratchpad, not the project) at 320/390/768/1024/1280/1440: screenshots, bounding boxes, link `href`/`target`/`rel`, and console errors (none). `npm run build` succeeds.
