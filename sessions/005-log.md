## What Was Done

## Work Log

- **Audit — transitions:** Grepped `src/style.css` for `transition` and `animation` properties. Found 4 properties needing fallbacks: `.nav__link` (color), `.overview__read-more` (color + border-color), `.retail__link` (opacity), `.modal__close` (border-color + color). Also identified `scroll-behavior: smooth` on `html` as requiring a reduced-motion override. Added a single `@media (prefers-reduced-motion: reduce)` block at the bottom of `style.css` covering all five.
- **Breakpoint audit — hero logo critical fix:** The `.hero__logo-wrap` was hardcoded at `width: 378px` while centered with `left: 50%; transform: translateX(-50%)`. The `.top-sections` wrapper applies 20px padding each side, so the inner container at 390px is 350px — the logo clipped 14px each side. At 320px it clipped ~49px each side. Fixed by changing to `width: min(378px, 94%); aspect-ratio: 378/215; height: auto`. Desktop override at 768px+ still sets explicit `width: 700px; height: 398px`, so no desktop regression.
- **Scroll-lock:** Created `src/js/scroll-lock.js`. Uses `IntersectionObserver` (threshold 0.1) on `[data-scroll-lock="true"]`. On first intersection: captures `window.scrollY`, sets `overflow: hidden` on both `html` and `body`, then after 1500ms clears overflow and snaps back with `scrollTo({ behavior: 'instant' })`. One-shot: `observer.disconnect()` after trigger. Skipped entirely when `prefers-reduced-motion: reduce` is active. Added `<script type="module">` tag to `index.html`.
- **IntersectionObserver boilerplate:** Created `src/js/observer.js`. Selects `[data-animate]` elements (none exist yet in Phase 4). Adds `is-visible` class on intersection; unobserves after trigger. No styles exist for `.is-visible`; no visual effect. Added `<script type="module">` tag to `index.html`.
- **RESPONSIVE.md:** Documented layout state for all 8 sections at all 6 breakpoints. Noted two non-critical cosmetic issues: (1) no max-width container — content stretches on wide viewports; (2) hero desktop logo uses absolute pixel position calibrated to 1440px Figma canvas — may look off at intermediate tablet widths. Both deferred to Phase 5 (Hero Revisions).
