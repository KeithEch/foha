## Work Log

- **Seal → FOHA logo:** Copied `FOHA_400.png` (407×400px) from source into `public/images/`. Replaced `overview__seal-wrap` div and `seal.png` img with a simple `img.overview__logo` pointing to `FOHA_400.png`. Alt text: `"Fraternal Order of High Adventure"` (user-specified — do not invent alt text).
- **Card restack:** Changed `.overview__card-inner` to `flex-direction: column; align-items: center` so the logo sits above the text, centered in the container.
- **Removed "Read more" button:** Removed the `<button class="overview__read-more modal-trigger">` from `index.html`. Cleared the modal's default hardcoded title and body content. Modal structure kept for gallery lightbox. Removed all `.overview__read-more` CSS rules and the transition-none override.
- **1440px column split:** Added `flex: 55` on `.overview__card-col` and `flex: 45` on `.overview__illustration-col` inside the 1440px block.
- **Desktop illustration height:** At 1024px: `height: 950px` (≈120% of estimated card height); at 1280px: `height: 912px`. Added `object-position: left center` at 1024px so right-side clipping occurs rather than top/bottom. At 1440px: `height: auto` (natural proportions give ~133% of card height with no clipping).
- **`padding-right: 0` at desktop:** Applied to `.overview` at 1024px, 1280px, and 1440px so the illustration bleeds to the right edge.
- **Mobile viewport fill + overlap:** Base `.overview__illustration-img` changed from `height: 544px` to `height: 100vh`. Base `.overview__card-col` given `position: relative; z-index: 1; margin-top: -200px` to overlap the illustration's bottom. Reset `margin-top: 0` in the 768px block.
- **Top-crop fix:** Added `object-position: top center` to the base `.overview__illustration-img` rule. At wide mobile widths (~760px), `object-fit: cover` was cropping the illustration top; pinning to top center clips the bottom instead, which sits under the card.
- **Mobile bottom spacing:** Added `padding-bottom: var(--space-72)` to base `.overview` for 390px and 760px breakpoints. The 768px block's `padding` shorthand resets this at all desktop breakpoints, leaving 1024px unchanged.
- **Card outer background:** Removed `mix-blend-mode: overlay` from `.overview__card-outer::before`, letting `bg_pattern.jpg` render directly as the card background without blending.
- **CMS — second paragraph:** Added `overview.paragraph` to `sections.json`, `config.yml`, `load-content.js`, and wired `data-content="overview.paragraph"` to the second `<p>` in `index.html`.
- **Max-width:** Added `max-width: 1680px; margin-inline: auto` to `.overview` base rule, matching Hero, About.
- **Breakpoint verification:** User confirmed Overview renders correctly at 320px, 390px, 768px, 1024px, 1280px, 1440px.
